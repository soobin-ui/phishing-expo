# 낚였습니다 — 피싱 체험 프로그램

2026 산학연협력 EXPO 안전체험관용 태블릿 체험 프로그램입니다.

## 실행하기

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5175 로 접속합니다.
(개발 중에는 PC 브라우저 창을 세로로 길게 줄이면 태블릿과 같은 화면으로 보입니다.)

## 문구를 고치고 싶을 때

코드를 건드릴 필요 없이 아래 파일만 열어서 고치면 됩니다. 저장하면 화면에 바로 반영됩니다.

| 파일 | 들어 있는 것 |
|---|---|
| `src/content/ui.json` | 화면에 보이는 버튼·안내 문구 전부 |
| `src/content/questions.json` | 1막 질문 7개와 보기 |
| `src/content/reveal.json` | 2막 리빌 카드 8장의 문구 |
| `src/content/scenarios.json` | 피싱 시나리오(메시지·선택지·위험 신호) |
| `src/content/report.json` | 취약 유형 4종과 오늘의 수칙 |

> `id`로 시작하는 값은 프로그램이 서로를 찾는 이름표이므로 바꾸지 마세요. 큰따옴표 안의 한글만 고치면 됩니다.

## 운영자 화면

체험 중 아무 화면에서나 **화면 우측 상단 구석을 5번 연속** 누르면 열립니다.
오늘 체험 인원·완주율·평균 소요시간·방어 성공률을 보고, CSV를 내려받을 수 있습니다.

기록은 **그 태블릿 안에만** 저장됩니다(서버 없음). 행사 후 태블릿마다 CSV를 내려받아 합치면 전체 집계가 됩니다.
